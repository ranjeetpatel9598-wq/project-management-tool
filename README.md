# Project Management Tool (CodSoft Level 3 Task 2)

This is a full-stack web application designed to help users organize their work by creating projects and managing individual tasks within them.[cite: 1, 6]

## Features:
* **Project Creation:** Users can create multiple projects with unique titles.[cite: 1, 6]
* **Task Assignment:** Add specific tasks to each project.[cite: 1, 6]
* **Deadline Tracking:** Set and view deadlines for every task to stay on schedule.[cite: 1, 6]
* **Progress View:** A clean dashboard to track all projects and their associated tasks at once.[cite: 1, 6]

## Tech Stack:
* **Frontend:** React.js[cite: 1, 6]
* **Backend:** Node.js & Express.js[cite: 1, 3]
* **Database:** MongoDB[cite: 1, 3, 5]

## How to Run Locally:
1. Clone the repository.
2. In the `/server` folder, run `npm install` and `npm start`.[cite: 2, 4]
3. In the `/client` folder, run `npm install` and `npm start`.[cite: 2, 6]
4. Ensure MongoDB is running on `localhost:27017`.[cite: 2, 3]
